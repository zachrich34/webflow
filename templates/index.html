Questions fréquentes

Est-ce que mes données sont sécurisées ? ▾
Oui. WebFlow fonctionne entièrement en local sur votre machine. Vos données sont chiffrées avec AES-256 et votre mot de passe maître ne quitte jamais votre appareil.
Quels navigateurs sont supportés ? ▾
WebFlow supporte Chrome, Firefox, Opera GX, Microsoft Edge et Brave.
Les mots de passe sont-ils transférés directement ? ▾
Les mots de passe sont exportés dans un fichier CSV dans le dossier de profil du navigateur de destination. Vous devez ensuite les importer manuellement via le gestionnaire de mots de passe du navigateur.
Puis-je transférer entre deux profils du même navigateur ? ▾
Oui, vous pouvez transférer entre deux profils différents du même navigateur, mais pas vers le profil source identique.
Mes données sont-elles envoyées sur internet ? ▾
Non. WebFlow tourne entièrement localement. Aucune donnée n'est envoyée à des serveurs externes. Votre compte est stocké localement sur votre machine.
